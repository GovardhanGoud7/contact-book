# Contact Book

A command-line contact book written in Java. Contacts are saved to a file, so they are still there the next time you run it.

## Features
- Add contacts with name, phone, and optional email
- View all contacts sorted by name
- Search by name or phone number
- Edit and delete contacts
- Input validation for phone numbers and emails
- Automatic saving to `contacts.txt`

## How to run
1. Install JDK 17 or newer
2. Download `ContactBook.java`
3. Run: `java ContactBook.java`

## How to use
Type a number from the menu (1 to 6) and follow the prompts. Choose 6 to quit.
